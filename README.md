# Dev. Moamal Skills for AI Agents

A curated collection of specialized skills for AI coding agents.

## Skills

- **[good-designer](./skills/good-designer/SKILL.md)**: Enforce intentional, human-crafted UI/UX design and eliminate generic AI aesthetic patterns. Synthesized into 7 core pillars with dual-mode (Build & Audit) behavior and framework-agnostic rules.
- **[bun-backend](./skills/bun-backend/SKILL.md)**: Enforce high-performance, modular, and type-safe backend architecture for Bun using Hono, Drizzle ORM, Zod, and a strict 3-tier vertical slice (Route $\rightarrow$ Service $\rightarrow$ Repository) design. Includes [production reference templates](./skills/bun-backend/references/templates.md) and portable [project rules](./skills/bun-backend/rules.md).
- **[reactjs-frontend](./skills/reactjs-frontend/SKILL.md)**: Enforce high-performance, modular, and type-safe frontend architecture for React using Vite, TypeScript, Tailwind CSS, TanStack Query & Router, Zustand, Zod, Lucide React, Sonner, and Vitest. Includes [production reference templates](./skills/reactjs-frontend/references/templates.md) and portable [project rules](./skills/reactjs-frontend/rules.md).
